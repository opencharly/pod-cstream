# 2026.242.0544 — feat: build the streamer and give the image webrtcsink

## Summary

Build and install the streamer, and give the image the one element that can carry its stream.

Three things, and the third is the one worth reading:

1. **`gst-plugin-rswebrtc`** joins the package list. Arch splits `gst-plugins-rs` into one package
   per plugin, and `webrtcsink` lives in `gst-plugin-rswebrtc` — **not** in
   `gst-plugin-webrtchttp`, which is the WHIP/WHEP pair and has no `webrtcsink` at all. The
   packaged series is `0.15.3`, which is the version the architecture pins, so no
   build-from-source layer is needed.
2. **`cstream-streamer` is built and installed** alongside the gateway and the leader, from the
   same pinned `charly-streamer` commit.
3. **`cstream-webrtcsink-registered` asserts the ELEMENT, not the package.** A plugin `.so` can be
   installed and still fail to load — an ABI skew against the system GStreamer is the usual way —
   and a package-database check cannot tell those apart. `gst-inspect-1.0 webrtcsink` can.
